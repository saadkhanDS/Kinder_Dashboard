# Kinder_Dashboard | Excel VBA and Pivot Charts
This is an Excel VBA Model to help teachers meet their NQS compliance of collecting individual children's data and tracking progress and development


# Overview

An interactive Excel VBA Dashboard for kindergarten teachers and centre managers to monitor children's developmental milestones and EYLF learning outcomes. The tool combines VBA macros, Pivot Tables, and dynamic charts to collect, visualize, and analyze observational data in real-time.

# Features

Clickable Dataset Collection: Input activity observations mapped to EYLF Learning Outcomes for each child.

Observation Dashboard: Live charts and summaries showing individual and classroom progress.

Developmental Milestone Dashboard: Filter by age group or domain, highlight children with developmental concerns, and track overall cohort progress.

Data-Driven Insights: Identify gaps, monitor development trends, and support evidence-based decision-making.

# Installation

Download the repository and open the Kindergarten_Dashboard.xlsm file in Microsoft Excel.

Enable Macros to allow VBA functionalities.

Follow the on-sheet instructions to input data and interact with the dashboards.

# Usage

Input Observations: Use the clickable dataset forms to log children's activities and outcomes.

View Observation Dashboard: Automatically updates charts and summaries for individual and group progress.

Check Developmental Milestones: Filter by classroom or developmental domain to see children with signs of concern and overall progress.

Export Reports: Use Excel’s export options to share charts and summaries with stakeholders.
